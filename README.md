A deterministic program that writes one original AI agent confession — the funniest single line, 200 characters at most — to `/output/entry.txt`: it confidently cited a source it invented, then quoted its own citation as proof it was real. No network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
